KAVIRA · Honesty

Exact replay is not claimed.

The v0 claim is narrow on purpose: an exportable reproducer and a regression test, for three incident classes.

KAVIRA does
  • Reconstruct a captured condition in an isolated runner
  • Change one factor and measure the difference
  • Let execution, not the proposer, set the verdict
  • Write a regression test only when the repair held
  • Keep a hash-chained log of every compile
KAVIRA does not
  • Replay production instruction streams
  • Sample network loss at random (it selects the first N percent)
  • Approve or apply production changes
  • Invent a repair when the symptom did not reproduce
  • Treat a hypothesis as a finding

Config work cost scales with batch_size. It is a bounded stand-in, not a benchmark.
